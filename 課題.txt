★プロジェクト概論　初回課題

　自分の名前のファイルを作成して、リポジトリに push してみよう！

目的：
　Git の基本操作（clone / add / commit / push）を体験しよう。

---

【手順1】自分の名前のファイルを作成する
　例：山田太郎.txt

　ファイルの中身は自由です。
　現時点の感想（簡単そう／難しそう／まだよく分からない など）を書いてください。

---

【手順2】Git に登録してコミットする
　以下のコマンドを順に実行してください。

　```bash
　git add 山田太郎.txt
　git commit -m "自分のファイルを追加"
　```

---

【手順3】リモートに push してみよう
　```bash
　git push
　```

　※「rejected」などと表示された場合は、まず pull してから再度 push してください。
　```bash
　git pull
　git push
　```

---

【注意】
・この課題では「develop」ブランチを使います。  
　ブランチ名が「main」になっている場合は、次のコマンドで切り替えてください。

　```bash
　git switch develop
　```

・他の人のファイルを編集しないようにしましょう。

---

提出完了の目安：
　GitHub 上のリポジトリに「自分の名前のファイル」が見えたら成功です。
